## Build the image

```bash
docker compose -f docker/docker-compose.headless.yaml build
```

Base image: `nvidia/cuda:12.1.1-cudnn8-devel-ubuntu22.04`
Python: `3.10` (managed by `uv` in `/opt/venv`)
Install strategy: `uv sync --frozen` (from `uv.lock`; includes `nvidia-curobo` CUDA ext — first build >= 20 min)

Quirks resolved:
- `needs_devel_base` + `needs_torch_cuda_arch` — `nvidia-curobo` compiles CUDA C++ extensions at build time; devel base + `TORCH_CUDA_ARCH_LIST="7.0;7.5;8.0;8.6;8.9;9.0+PTX"` + `CUDA_HOME=/usr/local/cuda` are required
- `needs_vulkan_icd` — SAPIEN ray-tracing requires Vulkan ICD JSON files (`nvidia_icd.json`, `nvidia_layers.json`)
- `needs_render_libs` + `needs_setuptools_pin` — SAPIEN / gymnasium render deps and setuptools compatibility

## Bring the container up

```bash
docker compose -f docker/docker-compose.headless.yaml up -d
docker exec -it robotwin-headless bash
```

For an X11-enabled session (GUI apps, SAPIEN visualiser):

```bash
xhost +local:docker
docker compose -f docker/docker-compose.x11.yaml up -d
docker exec -it robotwin-gui bash
```

Only one of the two profiles may run at a time — headless uses `container_name: robotwin-headless`, x11 uses `robotwin-gui`.
