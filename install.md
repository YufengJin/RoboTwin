# RoboTwin install

Reproducibility recipe for bringing up the RoboTwin dev container from a fresh clone. Regenerated by the `benchmark-env-generator` skill; manual edits will be overwritten on the next skill run. For the accompanying smoke-test log, see [`history.md`](history.md); for task semantics, see [`benchmark.md`](benchmark.md).

## 1. Host prerequisites

| Item | Minimum | Notes |
|------|---------|-------|
| GPU | NVIDIA Turing+ (sm_70) | CUDA extensions compiled for `7.0;7.5;8.0;8.6;8.9;9.0+PTX`. |
| Driver | ≥ 525 | Required for the CUDA 12.1 base image. |
| Docker | ≥ 24 | Compose v2 plugin. |
| NVIDIA Container Toolkit | Latest | Enables `--gpus all` / compose `deploy.resources.reservations.devices`. |
| Disk | ≥ 40 GB free | CuRobo + SAPIEN + torch wheels + RoboTwin asset zip. |
| RAM | ≥ 16 GB | CuRobo build peaks around 10 GB. |

## 2. Clone

```bash
git clone https://github.com/TianxingChen/RoboTwin.git
cd RoboTwin
```

If upstream access is not available, use the path you already have: `/home/yjin/repos/RoboTwin`.

## 3. Build the image

From the repo root:

```bash
docker compose -f docker/docker-compose.headless.yaml build
```

First build takes **≥ 20 minutes** (CuRobo CUDA-ext compile dominates). The Dockerfile is pinned to `nvidia/cuda:12.1.1-cudnn8-devel-ubuntu22.04`; to switch to cu118 edit `[[tool.uv.index]]` + `[tool.uv.sources]` in `pyproject.toml`, regenerate `uv.lock` (see `docker/README.md`), and rebuild.

## 4. Start the container

Headless profile (server / training / CI):

```bash
docker compose -f docker/docker-compose.headless.yaml up -d
docker exec -it robotwin-headless bash
```

The entrypoint:

1. Clears `/tmp/entrypoint_done` at start.
2. Runs `uv pip install -e . --no-deps` only if `setup.py` exists (the root `pyproject.toml` is dependency-lock-only, so this is a no-op in the default layout).
3. With `ROBO_AUTO_ASSETS=1` (default), runs `script/_download_assets.sh` if `assets/embodiments`, `assets/objects`, or `assets/background_texture` is empty. The assets are downloaded into the bind-mounted repo on the host and persist between runs.
4. `touch /tmp/entrypoint_done` so external waiters can poll for readiness.

X11 profile (local GUI):

```bash
xhost +local:
docker compose -f docker/docker-compose.x11.yaml up -d
docker exec -it robotwin-x11 bash
```

Only one profile can be up at a time (headless and x11 share the `robotwin:latest` image but use different `container_name`s).

## 5. Sanity check

One-shot render self-test (no `up -d` needed):

```bash
docker compose -f docker/docker-compose.headless.yaml run --rm robotwin \
  bash -lc 'python -c "import torch; print(torch.cuda.is_available())" && python script/test_render.py'
```

Expected: `True` and a green `Render Well`.

## 6. Smoke tests

The four-tier smoke contract (L1 reset+step, L2 reward-finite, L3_IL random policy server + run_demo + run_eval) is captured in [`history.md`](history.md) for this machine. To rerun yourself:

```bash
# L1 — reset + 10 env.take_action (no reward assertion)
docker exec robotwin-headless bash -lc 'cd /workspace/RoboTwin && python -c "
import sys, numpy as np; sys.path.insert(0, \"script\")
from robotwin_run_utils import class_decorator, build_eval_args_from_yaml
env = class_decorator(\"beat_block_hammer\")
y = build_eval_args_from_yaml(\"beat_block_hammer\", \"demo_clean\"); y[\"eval_mode\"]=True; y[\"render_freq\"]=0
env.setup_demo(now_ep_num=0, seed=100000, is_test=True, **y)
dim = int(np.asarray(env.get_obs()[\"joint_action\"][\"vector\"]).ravel().shape[0])
for _ in range(10): env.take_action(np.random.uniform(-0.05,0.05,dim), action_type=\"qpos\")
env.close_env(); print(\"L1 OK dim=\", dim)
"'

# L3_IL — random policy server + run_demo + run_eval
docker exec -d robotwin-headless bash -lc \
  'cd /workspace/RoboTwin && python tests/test_random_policy_server.py --port 8000 --action_dim 14 > /tmp/random_policy_server.log 2>&1'

docker exec robotwin-headless bash -lc '
for i in $(seq 1 30); do
  python -c "import socket,sys; s=socket.socket(); s.settimeout(1.0); s.connect((\"localhost\",8000)); sys.exit(0)" 2>/dev/null && echo "server up" && exit 0
  sleep 1
done; echo "server failed"; cat /tmp/random_policy_server.log; exit 1'

docker exec robotwin-headless bash -lc \
  'cd /workspace/RoboTwin && python scripts/run_demo.py --task_name beat_block_hammer \
      --task_config demo_clean --policy_server_addr localhost:8000 \
      --num_resets 1 --log_dir ./logs --save_video'

docker exec robotwin-headless bash -lc \
  'cd /workspace/RoboTwin && python scripts/run_eval.py --task_name beat_block_hammer \
      --task_config demo_clean --policy_server_addr localhost:8000 \
      --n-episodes 1 --log_dir ./logs --save_video'

docker exec robotwin-headless bash -lc 'pkill -f test_random_policy_server.py || true'
```

Run-dir artefacts:

- `logs/demo/<task>--<ts>/demo.log`, `demo.mp4` (if `--save_video`).
- `logs/eval/<task>--<ts>/eval.log` (rolling success rate + `FINAL RESULTS`), `episode_000_success={True|False}.mp4`.

## 7. Teardown

```bash
docker compose -f docker/docker-compose.headless.yaml down
```

The image and mounts persist; the next `up -d` is seconds.
